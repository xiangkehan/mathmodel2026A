## 一、竞赛论文标准结构

### 1.1 总体顺序（固定，不得改名/调序/合并/省略）【结构】

| 序 | 板块 | 该写什么 | 语言风格 | 常见扣分点【写作】【评审】 |
| --- | --- | --- | --- | --- |
| 前置 | **论文题目** | 一行动词性标题（对象+方法+问题） | 16 pt 宋体加粗居中 | 标题泛化（"关于烘干的数学建模"） |
| 前置 | **摘要** | 四段式：问题与挑战 → 方法 → 关键结果（带数值）→ 验证与创新 | 客观、定量、无第一人称 | 无定量结果／与正文口径不符／超一页／塞公式图表 |
| 前置 | **关键词** | 4–6 个：≥2 个方法词 + ≥2 个领域词 | 关键词之间**空格分隔，不用分号**【版面】 | 关键词空泛（"数学建模""优化"） |
| 一 | **问题重述** | `1.1 问题背景`（现实情境、需求与直接矛盾，2–3 句，不写空泛意义）+ `1.2 问题提出`（用自己的语言逐问说明"要解决什么+拟采用什么思路"，只给宏观方案） | 简洁、可核验，不照抄题面 | 大段复述题面；提前堆公式与结果 |
| 二 | **问题分析** | `2.n 问题n的分析`（n=小问数）：难点、信息关系、建模路线与选型理由（为什么用这套模型、对应题目哪条结构） | 逻辑推演，落到本题 | 只写"我们用了XX模型"不给理由；与第五章重复 |
| 三 | **模型假设** | 5–7 条，每条一句理由，只保留**实际使用**且能界定适用边界的假设 | `假设1：…（理由：…）` | 无支撑假设／假设过多或过少／假设与正文打架 |
| 四 | **符号说明** | **三线表**三列：符号 \| 含义 \| 单位/量纲；只列主要全局符号，首次进入正文仍需解释 | 表格化，与正文符号严格一致 | 符号重复定义／无单位／未定义先出现／量纲不一致 |
| 五 | **模型建立与求解** | 按小问分节（`5.n`），每问内部 `5.n.m` 按"数据预处理（确有）→ 模型的建立 → 模型的求解 → 必要的局部检验 → 结果的分析"闭环。按"变量与参数 → 假设依据 → 数学定义 → 算法 → 运行参数 → 实际结果 → 验证"展开 | 推导完整、步骤可复现 | 建模/求解/结果揉成无层级长节；只报数字不解读；结果无图支撑 |
| 六 | **模型检验** | 只集中呈现**决定主要结论可信度**的误差、灵敏度、稳健性检验，不罗列所有诊断 | 报偏差量级并解释含义 | 灵敏度只改代入值不重新求解；参数乱选；同一证据在第五/六章重复 |
| 七 | **模型优缺点评价** | `7.1 优点` / `7.2 缺点` / `7.3 改进`；优缺点必须有本题证据，改进必须对应已陈述缺点 | 证据化、不写套话 | 空泛套话；提改进却不对应缺点 |
| 八 | **参考文献** | 正文引用与文末条目**双向对应**；GB/T 7714-2015 格式 | 作者/题名/年份/来源/卷期页/DOI 以原始出版页为准 | 手工条目未被引用；重复出现两个"参考文献"标题 |
| — | **附录** | 官方允许或要求的附录：完整代码清单（`listings`，Python 高亮）、长推导、大数据表 | 可复现、可追溯 | 把正文该讲的推导挪进附录；代码清单与交付代码不一致 |

### 1.2 摘要写法定量要求

- **四段式**，每段首句给结论，段内**必须出现具体数值**（本题：`t_f=57.1799 h`、`0.047 mm`、`0.088 mm`、`+78.57 h`、`51.1667 h` 等，与正文/表格/图完全一致）。
- 篇幅：**CUMCM 原则上不超过一页**（官方硬约束）【格式】；本刊现状 588 中文字 / 892 字符，已在第 1 页整块容纳（`06-论文/main.tex` 的 `\@maketitle` 已去掉空 `\author{}` 行）。
- **不放公式、图表**；摘要最后写，基于定稿正文。
- 结论章"**一图一数一句**"：每条结论紧跟一张图 + 一个数值 + 一句解释【写作】。

### 1.3 篇幅与结构硬约束

| 项 | 规定 | 出处 |
| --- | --- | --- |
| 正文页数 | **22–30 页**（含摘要到参考文献；CUMCM 2026 官方正文 ≤30 页为硬约束，22 页为质量目标） | 【版面】【格式】 |
| 摘要 | 独立成页或控制在第一页内，**不超过一页** | 【结构】【格式】 |

| 篇幅来源 | 只能靠必要推导、机理说明、算法步骤、候选比较、结果解释、验证、敏感性、边界与**可追溯**图表撑起；禁止空白页、放大字号、异常行距、重复内容、长代码凑页 | 【版面】 |

### 2.3 三线表

- 统一用 `booktabs`（`\toprule/\midrule/\bottomrule`），**不用竖线**；符号说明表固定三列"符号 \| 说明 \| 单位"【版面】【模板】。
- 表题置于**表上方居中**，格式"**表1** ……"；表按正文出现顺序连续编号【版面】。
- 单元格文字不得为容纳宽度而删改；列宽用定宽 `p{}` 逐列实测（本刊表 3/5/12/14/15 已按此改造，探针文件 `08-临时/_measure2.tex`），保证 0 Overfull【本刊既有做法】。
- 表格必须参与论证，不做装饰表；每个表至少被正文引用一次【图版面】。

### 2.4 公式

- 公式必须是**原生 LaTeX**（或 Word 原生 OMML），**禁止截图/纯文本 LaTeX**【格式】【LaTeX】。
- 用 `equation`/`align` 环境并**编号**；按正文出现顺序连续编号（本刊 `\numberwithin{equation}{section}` 为"章.序"式，可保留）。
- 每个公式在正文中至少被引用一次；变量首次出现必须解释、与符号说明表一致【结构】。
- 优化类小问的"模型汇总"用**一个完整显示公式**：目标函数在上、`s.t.` 后纵向大括号收拢约束；括号/编号/索引不得越出正文宽【版面】。
- 公式不得被推到下一页或与引导句分离；跨页公式须人工检查【版面】。

### 2.5 图与题注

| 条目 | 规定 | 出处 |
| --- | --- | --- |
| 位置 | 图居中；**图题置于图下居中**，格式"**图1** ……"（或分章式"图 4-2"，本刊全篇须统一） | 【版面】 |
| 编号 | 图、表、公式均按正文出现顺序连续编号 | 【版面】 |
| 引用 | 每幅图在**浮动环境之外**至少被正文 `\ref` 引用一次；孤儿图（无引用）视为不合格 | 【LaTeX】【自审】 |
| 排布 | 图必须与引入文字/推导/结果解释**同页或紧邻**；**单个浮动体不得独占或近乎独占一页**；过大时拆面板、压留白、改长宽比 | 【版面】 |
| 子图 | 多面板必须一次画成**一个矢量 PDF**，不得把多个独立 PDF 塞进 LaTeX `subfigure` 拼接 | 【图版面】 |
| 图注内容 | 写清"回答什么问题 + 关键数字 + 怎么读"；误差类图必须注明误差类型（SD/SEM/95% CI/IQR）与 n | 【图工具】 |
| 尺寸一致性 | LaTeX 里的 `width` 一旦确定即**不得在正文中再缩放**；改图必须回源图改，不得靠改 `width` 补救【图版面】 | 【图版面】 |

### 2.6 参考文献

- 格式 **GB/T 7714-2015**；建议含英文文献【模板】。
- 正文 `\cite` 键必须能在 `\bibitem`/`.bib` 中找到，**手工条目不得未引用**；双向核对脚本化（本刊 `06-论文/check_refs.py`）【LaTeX】。
- 用 `thebibliography` 时须**抑制其自动 `\refname`**，避免同时出现两个"参考文献"标题【版面】。
- 参考文献是论文最后一个板块；正文结束于参考文献，支撑材料独立交付【结构】【版面】。

### 2.7 附录与代码清单

- 附录放：长推导、量纲/判据门禁表、标定流程、**完整代码清单**（`listings` + Python 语法高亮，中文注释）【模板】。
- 代码清单必须与 `02-代码/` 交付版本一致（本刊附录 B 的复现清单 + `论文.zip` 的哈希锚点机制）【LaTeX】。
- 附录不承接正文结论；正文自足。

### 2.8 编译与交付门禁

- 引擎：中文基线 **XeLaTeX**；用 `latexmk` 完成交叉引用（本刊 `latexmk -xelatex main.tex`）【LaTeX】。
- 交付前必须满足（逐条可脚本化）【LaTeX】【自审】：
  1. 编译 **0 错误**、**0 undefined reference / 0 undefined citation**；
  2. **0 `Missing character`**（中文缺字 = 空白方框，必须归零）；
  3. **0 `Overfull \hbox`**（表格/公式越界的第一信号）；
  4. PDF 嵌入 TrueType 子集（`pdf.fonttype=42`），无 Type 3；位图 ≥300 dpi；
  5. 记 PDF 总页数、正文起始页、附录起始页与**正文页数**（正文上限不得用总页数替代）；
  6. 逐页渲染抽检：页首/页末残句、标题孤行、图题跨页、表格越界、空白页、大浮动体独占页；
  7. 三个自查全过：数字一致性（`check_numbers.py`）、引用双向（`check_refs.py`）、表格逐格（`check_table6.py`），另加摘要字数（`check_abstract.py`）。

### 3.2 面板与版式

1. **一图一论点**；单面板优先，相关的事并进同一张图 2–4 个面板（GridSpec 允许不等宽高）【图风格】。
2. **多面板一次画成一个 PDF**；面板标签 `(a)`/`(b)` 统一样式与位置（本刊：左上外侧粗体，`panel()`；数学建模惯例小写加括弧）【图工具】。
3. **判据可视化**：有阈值/上限/合格线时画 `axhline/axvline`（虚线 + 线旁短标签），例：水分浓度阈值 0.15 kg/kg、达标的 t_f 竖线【图风格】【示例2】。
4. **不确定性必须画出**：有重复/区间用 `fill_between` 或 `errorbar`，图注注明口径与 n；不得只画一条光溜曲线【图风格】【图工具】。
5. **不用双 Y 轴**，除非两个变量量纲相同；量纲不同一律拆上下子图或显式 `twinx` 并在两轴都写单位【图工具】【图风格】。
6. **色阶必须带 colorbar，colorbar 必须有 label + 单位**；多面板共用 colorbar 用 GridSpec 的 `cax=`（不能用 `ax=axes`，会被 `tight_layout` 压掉）【图工具】【图风格】。
7. **层次 `zorder`**：网格/参考带 0–1、数据 2–3、标注 4+【图风格】。
8. **对数轴零值不得静默丢弃**：显式地板值（按该图真实下界现算，贴着最小值下方半个数量级），并在图注说明【图风格】。
9. **坐标轴只覆盖有数据的区间**；不出现 `1.0000`/`1.23456789` 这类刻度精度；log 轴在 label 里标 log【图工具】。
10. **图内文字最小化**：说明性长文、数据源、口径、偏差数字一律由论文 `\caption` 承载；图内只留必要的短标注（本刊 `plot_all.py` 的设计原则，且逐图打印 `[Fn]` 诊断行供写图注）【本刊既有 + 图工具】。
11. **异量纲不共轴**；每个面板只回答一个唯一问题，不得用不同图型重复展示同一数据【图工具】。
12. **图型多样性**：全文图型 ≥3 种；**同一种图型 ≤3 次**【图工具】【图风格】。
