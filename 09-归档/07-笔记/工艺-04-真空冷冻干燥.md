## 一、研究问题

1. 中药材 / 中药饮片真空冷冻干燥（冻干）的**完整工艺链**是什么：预冻温度与速率 → 一次干燥（升华）搁板温度与真空度 → 二次干燥（解吸）温度 → 总时长。
2. 冻干与热风干燥在**含水率、有效成分、外观**上的定量差异。
3. 冻干是否适用于**鲜药材整体**（而不是提取物/药液）。
4. 冻干的**成本量级**与热风的对比。
5. **关键追问**：本题《药材的烘干问题》把工艺设定为「热风、28→50 ℃、2–3 天、两阶段」，这套设定在真实工艺里是否常见、参数是否合理？

## 三、结论

### 3.1 主流工艺链（三段式，参数区间）

1. **前处理**：清洗、分级整形；鲜药材通常**切段/切片**（如铁皮石斛切 1.5–2 cm、山药切 3 mm）以缩短传质路径；常配 85 ℃ 热水灭酶 4–6 min（铁皮石斛）。
2. **预冻**：目标是把自由水完全冻结到**共晶点以下**，常见 **−18 ~ −50 ℃**，保温 **1–8 h**；预冻速率 **0.3–5 ℃/min**（慢冻→大冰晶→升华快但结构损伤；速冻→小冰晶→结构保护好）。人参共晶点约 −15 ℃（厂商），蛋白类/药液类常取 −40 ~ −50 ℃。
3. **一次干燥（升华）**：抽真空至 **10–60 Pa**（医用常 <20 Pa）；搁板温度从共晶点以下**缓慢升温**（典型 0.2–0.8 ℃/min 或每小时几度），物料温度始终低于坍塌温度；此段去除 **90–95%** 的水，是**最耗能**的一段（占总能耗 **48%**），也是**耗时最长**的一段（F&V 典型 8–9 h，实际可从数小时到数十小时）。
4. **二次干燥（解吸）**：搁板升到 **20–45 ℃**（≤玻璃化转变温度），真空度不变或更低，脱除结合水；终点含水率 **1–5% w.b.**（部分资料 0.5–3%）。
5. **后处理**：破真空、充氮/干燥环境包装（冻干品疏松多孔，极易吸湿氧化）。

### 3.2 总时长量级

- 切片/小段药材：**6–20 h**。铁皮石斛茎段 5.7 h（20 Pa、50 ℃）；山药片 14 h；香葱类冻干转热风联合 125 min。
- 整根/整支药材：**24–48 h**（天麻专利：普通冻干 24–48 h；人参整支 18–24 h）。
- 微波/红外辅助冻干：可压到 **6–8 h**。
- **结论：冻干的总时长量级是「数小时到两天」，不超过 2 天**，与「2–3 天」不完全重合但同量级。

### 3.3 冻干 vs 热风（含水率 / 有效成分 / 外观）

| 维度 | 冻干 | 热风干燥 |
|---|---|---|
| 终点含水率 | 更低，常 **1–5% w.b.** | 常 **10–14% w.b.**（人参 ≤12%、三七 ≤14%） |
| 有效成分 | **更高**：西洋参总皂苷 +42.5%（vs 热风）；三七皂苷/三七素更优（**但三七皂苷 R1 反而低于 60 ℃ 热风**）；铁皮石斛多糖/甘露糖更优 | 高温有氧环境导致皂苷降解、褐变 |
| 外观 | 收缩小、疏松多孔、色泽接近鲜品、复水快；缺点是**脆性大易断**、需防潮包装 | 收缩/结壳、色变深、复水慢 |
| 时长 | 长（1–2 天，整根） | 短（切片 12–30 h，整根 24–48 h） |
| 能耗/成本 | 热风的 **3–10 倍**（不同口径：+321%、4–10 倍、8–14 vs 2.8–4.5 kWh/kg 水） | 最低 |

### 3.4 冻干是否适用于「鲜药材整体」

**是，已有产业实践**，但工业上仍以切片/切段为主：

- **整根/整支**：三七（刘勇等 2019，中草药 50(23): 5714-5723，比较阴干/晒干/**冻干**/热风对三七**药材**外观性状与内在结构的影响）；人参整支冻干（专利 CN107260784A、CN108634157A「新鲜人参的真空冷冻干燥加工方法」，均以整支鲜参为原料）；天麻块（CN107308350A）。
- **冻干「整支」的物理难点**：传质路径 ∝ 半径 → 整根干燥时间远长于切片，且内部易残留水分（专利 CN104721244B 明确指出现有冻干工艺「三七干燥不彻底、水分不能除尽、成品绵软不酥脆」）。
- **提取物/药液冻干**是另一条独立路线（西林瓶灌装药液、人参提取液冻干），不能与「鲜药材整体」混为一谈。

| 冻干有效成分高于热风 | **中强** | 西洋参 +42.46%、三七多篇一致；但存在**反例**（三七皂苷 R1 冻干 < 60 ℃ 热风），且不同研究口径（皂苷种类、温度）不可直接合并 |
| 具体药材的预冻温度/搁板温度/真空度 | **中** | 多来自单篇论文（三七 56.9 Pa/45.2 ℃、石斛 20 Pa/50 ℃/1.5 ℃·min⁻¹）或专利，样本少、无重复验证 |
| 冻干总时长的分布 | **中弱** | 5.7 h（石斛茎段）、14 h（山药片）、18–24 h（人参整支）、24–48 h（天麻）之间跨度大，且整根数据主要来自专利 |
| 是否存在中药材冻干的国标/药典条款 | **强（否定结论）** | 检索多次未找到；只有设备标准 JB/T 20032-2012 与果蔬类地标 |

## 五、与题面设定的对照

**题面设定**：圆柱形药材 25 cm × r = 2 cm；初温 28 ℃；初始 **2.55 kg/kg 干基**（=71.8% w.b.）；烘房 28 → 50 ℃ 后恒定；总时长 **2–3 天**；分「预热平衡 + 恒温干燥」；目标各处 **0.15 kg/kg 干基**（=13.04% w.b.）。

**逐条判断**：

1. **"热风烘干 + 预热平衡/恒温干燥两阶段 + 50 ℃ 恒温" —— 符合真实常见工艺。**
   热风干燥是中药材产地加工中**应用最广**的方式（A3），根茎类常用 40–60 ℃；人参整根 40–50 ℃ / 24–48 h、三七切片 45–55 ℃ / 18–30 h（厂商参数表）。50 ℃ 属温和合理区间，低于多数皂苷明显降解阈值。
   但真实热风工艺**普遍分段控温/控湿**（前期稍高、后期降温，或阶段降湿），题面的「升到 50 ℃ 后基本恒定」是**简化**，不是真实标准做法。

2. **"2–3 天" —— 数量级合理，但偏长。**
   对 25 cm 长、半径 2 cm 的**整根**药材，热风干燥 24–48 h（厂商口径）与题面 48–72 h 同量级；题面偏长的一端可由热风风速低、装载量大、目标含水率更低解释。**结论：题面的时间设定在真实工艺里是常见量级，不算异常。**

3. **初始含水率 2.55 kg/kg 干基（71.8% w.b.）—— 合理。**
   鲜西洋参 >70% w.b.（A7），鲜根茎类多在 60–80% w.b.。**符合。**

4. **终点 0.15 kg/kg 干基（13.04% w.b.）—— 与药典限值自洽。**
   三七 ≤14.0% w.b.、人参 ≤12.0% w.b.，13.04% 正好夹在两者之间。**这说明题面的达标阈值不是随意设定，而是对齐了真实商品药材的水分标准。符合。**

5. **"题面这套设定是冻干吗？——不是。**
   冻干必须在**真空（10–60 Pa）**下、物料**全程冻结（−20 ℃ 以下）**，搁板温度是**三段程序控温**（预冻 −40 ℃ 级 → 升华 −20~0 ℃ → 解吸 20–45 ℃）。题面是**常压 50 ℃ 热风**，完全没有真空与冻结环节。
   **判定：题面描述的是热风干燥，与冻干是两条互斥的工艺路线，不能互相套用参数。** 若在建模中把题面的 $D$、$h_m$ 与冻干文献参数混用，属于口径错配。

6. **题面相对真实工艺的「不寻常」之处**（3 条）：
   - 题面附件 1 的烘房「水分浓度」（R3 已判为空气含湿量 $W$）在真实工艺中确实是**控制设定值轨迹**，但题面把它当作质量边界条件的环境含水率使用，真实产线上它对应的是**热风含湿量/相对湿度**，两者不能直接互换 —— 这是建模口径问题，不是工艺问题。
   - 真实工艺的**升温段（预热平衡）通常只有几十分钟到数小时**（物料热透），题面用 30 min 报告单独阶段，是合理的教学简化。
   - 真实热风工艺**装载量、风速、铺料厚度**是核心工艺参数（如铺料 ≤2 cm），题面完全没有给出 —— 它们是题面未建模的隐含自由度，也是「2–3 天」能否成立的关键。

## 六、遗留问题

1. **中药材冻干缺少国标/药典条款**：只查到设备标准 JB/T 20032-2012 与其他物料的加工技术规程（贻贝、金桔、黄花菜）。若需为论文引用「权威冻干工艺规范」，目前只能引综述与行业标准，**不能编造药典条款**。
2. **整根药材冻干的总时长缺少同行评议统计**：现有 18–24 h（人参整支）、24–48 h（天麻）主要来自专利，需进一步找期刊级的「整根/整支冻干曲线」论文。
3. **成本对比口径不统一**：3–10 倍的区间混杂了「同一物料实测（乌龙茶 +321%）」「综述估计（4–10 倍）」「厂商基准（8–14 vs 2.8–4.5 kWh/kg 水）」三种口径，无法直接给出一个可信的倍数点估计。若论文需要定量成本对比，建议只引 A6（Foods 2023）的综述区间并注明其未指定物料。
4. **未解决的问题**：当归冻干专用论文（A8）仅取到题录与摘要，具体预冻/搁板/真空/时长参数未取得（原文需付费或机构访问）。
