# q4_endo_fields.npz 说明

内生问题 4（耦合内生几何，R 由湿度场经闭合 C 预测）的完整时空场。
复现：`cd 03-数据 && python run_q4_endo_fields.py`（约 100 s）。

| 键 | 形状 | 单位 | 说明 |
|---|---|---|---|
| t_s | (507,) | s | 帧时刻，0 → t_f=181932.7 s，帧间隔 360 s |
| r_cm | (101,) | cm | **固定物理网格** 0–2.0 cm、步长 0.02 cm（非材料网格） |
| C | (507,101) | kg/kg（干基） | 水分浓度场；r>R(t) 处 NaN |
| T | (507,101) | ℃ | 温度场（内部开尔文计算、导出转 ℃）；域外 NaN |
| R_t | (507,) | cm | 每帧外半径 R_pred(t)（闭合 C 预测） |
| Cs | (507,) | kg/kg | 表面含水率 |
| Cc | (507,) | kg/kg | 中心含水率（末帧 0.1500≈达标） |

网格说明：径向为固定物理网格（r>R(t) 域外填 NaN）；空间重构为 q 内三点二次
（中心正则外推+单元中心+表面串联阻力值），时间帧由接受步线性插值。
