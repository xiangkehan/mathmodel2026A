# A 题工作目录

本目录（`C:\Project\数学建模2026\数学建模2026\A`）存放 **2026 年高教社杯全国大学生数学建模竞赛 A 题（药材的烘干问题）** 的全部工作内容：
题目参考、源码、中间数据、交付结果、论文图表、论文正文与过程笔记，都收在这一棵树下。

## 目录结构

```
A/
├── README.md          本文件：目录用途与命名约定
├── 00-最终方案.md     定稿执行方案（唯一执行依据，2026-09-11）
├── 01-题目/           题目与附件（只读参考，来自 ../../题目/A题 的副本）
│   ├── A题.md         题目正文（Markdown，含附录与公式）
│   ├── 附件说明.md     附件清单 + 数据字典 + 数据陷阱
│   ├── images/        正文中的表格/公式截图
│   └── 原始文件/        A题.pdf、附件1.xlsx、附件2.xlsx、附件3/result1~4.xlsx
├── 02-代码/           全部源码（Python）
├── 03-数据/           中间数据：参数表、网格快照（.npz/.csv）、运行日志
├── 04-结果/           最终交付文件 result1.xlsx ~ result4.xlsx
├── 05-图表/           论文用图（.png/.pdf）与表格导出（.csv）
├── 06-论文/           论文正文（LaTeX/Word）、参考文献、竞赛格式规范
├── 07-笔记/           过程记录：模型选型、参数取值、困难与解决、决策理由
├── 08-临时/           一次性试验、草稿；不入 git
└── 09-归档/           旧研究笔记与力学旧阶段数据产物归档（备查，可还原，见 MANIFEST.md）
```

## 规划要点与理由

- **按"数据流"分段**：`01-题目` 只读输入 → `02-代码` 计算 → `03-数据` 中间产物 → `04-结果` 交付 → `05-图表`/`06-论文` 输出，`07-笔记`/`08-临时` 旁路。
- **`01-题目` 是副本而非引用**：`../../题目/A题` 是五道题的公共归档，本目录留一份副本保证 A 题自包含、可离线查阅；改动只回写到本目录，公共归档不动。
- **交付物与中间产物分开**：`04-结果` 只放要提交的 `result1~4.xlsx`（附件 3 模板要求保留 4 位小数），中间网格、参数扫描一律进 `03-数据`，避免交错污染。
- **`08-临时` 不入 git**：随手试验、调试脚本、导出图片都放这里，随时可整体删除。
- **文件命名**：目录名用中文编号前缀（排序即阅读顺序）；代码文件名用 ASCII（`common_*.py`、`q1_*.py`、`q2_*.py`…）避免导入与工具链的编码问题；
  结果文件名必须严格用竞赛规定的 `result1.xlsx` ~ `result4.xlsx`。
- **提交包**：根目录 `论文/` 与 `论文.zip` 是提交用拷贝包（`02-代码`/`04-结果`/`05-图表`/`06-论文` 四目录的逐字节拷贝），不入 git；源目录改动后重新拷贝即可再生成。
