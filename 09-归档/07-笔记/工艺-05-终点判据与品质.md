# 工艺-05｜干燥终点判据、含水率限度与品质指标

> 检索代理笔记｜方向：现有（实际生产中的）药材烘干工艺一般是什么？
> 纪律：每条数据均来自实际检索；查不到写「未找到」。**所有含水率一律标注干基 / 湿基**。
> 本笔记只做「工艺-05」一个方向，不越界。

---

## 一、研究问题

要回答四问，外加一个元问题：

- **(a)** 中药材/饮片的**干燥终点**在生产现场用什么判据（定时、恒重、含水率抽样、感官）？
- **(b)** 药典与国标对各类药材的**水分限度**原文数值（0212 通则"不超过 13%"；枸杞 GB/T 18672；山药、黄芪、当归等）。
- **(c)** **水分活度 a_w** 与安全贮存的关系。
- **(d)** 干燥**品质评价指标**（有效成分保留率、色泽、复水性、皱缩率）及其标准测定方法。
- **元问题**：题面这套设定（28→50 ℃、总时长 2–3 天、目标 0.15 kg/kg **干基**）在真实工艺里是否常见、参数是否合理？

## 二、干基 / 湿基换算（先立规矩，此处极易出错）

定义：干基含水率 $C=m_w/m_d$（kg/kg，干料为基准）；湿基含水率 $W=m_w/(m_w+m_d)$。

$$W=\frac{C}{1+C}\qquad C=\frac{W}{1-W}$$

| 数值 | 干基 C (kg/kg) | 湿基 W (%) |
|---|---|---|
| 题面初值 | 2.55 | **71.83** |
| 题面终点 0.15 | 0.150 | **13.04** |
| 药典 0212 通用限 13% | 0.1494 | 13.0 |
| 《中药饮片质量标准通则（试行）》下限 7% | 0.0753 | 7.0 |
| 黄芪药典限 10% | 0.1111 | 10.0 |
| 山药片限 12% | 0.1364 | 12.0 |
| 当归药典限 15% | 0.1765 | 15.0 |
| 山药（毛/光）限 16% | 0.1905 | 16.0 |

**关键恒等式**：题面终点 **0.15 kg/kg 干基 ≡ 13.04% 湿基**，与药典 0212 通则默认限 **13%（湿基）** 在数值上重合。这一点是本次检索最重要的发现（见第六节）。
注意：药典/国标**一律以湿基（质量分数 %）表述**，题目用**干基**，两者不可直接比大小。

### 3.2 (a) 生产现场**干燥终点判据**（来源：论文/规范 + 厂商，已标注）

1. **"三法结合"判终点（最贴近生产现场的表述）**
   《干燥湿度与中药饮片水分关系浅析》（以**法半夏**为对象，参考网转引，2020）：
   "在生产现场可以通过**观察仪表上的湿度变化、人工触摸手法及快速水分测定法**三法结合来判断干燥终点，快速便捷，数据相对可靠。"
   并指出"仪表显示湿度由大变小、最终平衡，相对平衡时可以体现干燥终点出现，**平时单凭手摸法误差还是比较大**"。→ 即 **仪表排湿 + 感官（手摸）+ 快速水分** 三判据并联。

2. **定时 + 恒重（实验室/法定判据）**
   通则 0832 第二法：105 ℃ 下"干燥至恒重"（连续两次称重差异 ≤5 mg）。这是**检验/验收**判据，不是产线在线判据；产线用**卤素/红外快速水分仪**（3–5 min 出结果）替代，作过程控制。

3. **感官判据的官方法源**
   WFCMS 标准 6.2.3.3：「采用**手摸、眼观、嘴尝、鼻闻、火烧和水试**等传统方式进行性状鉴别」；药典 0212 四「性状」亦以感官（眼看/手摸/鼻闻/口尝）为主，并规定「药材和饮片不得有虫蛀、发霉」。
   药典 0212「检查」明确把**水分**列为相对独立的限量项 —— 说明终点不是纯感官说了算。

4. **工业 SOP 级时间/温度闭环（厂商资料，标注为厂商）**
   湖北孟氏中药饮片竣工环保验收报告：**带式干燥机，温度 60–80 ℃，时间 4–6 h**；辽宁/安徽类环评与验收报告亦见"干燥使产品含水率符合要求"的工序描述。
   兰浦科技（AI 中药干燥，厂商）宣称「自适应调整温度梯度、风速配比、干燥时长，精准判定干燥终点，**含水率控制 ±2%**」。

5. **归纳**：现场终点判据 = **定时（SOP 规定的干燥时长）+ 在线/快速含水率抽样（主判据）+ 感官（手摸/折断/色泽，辅助）+ 排湿仪表平衡（过程指标）**；"恒重法"只用于实验室检验与验证批。

### 3.3 (c) 水分活度 a_w 与安全贮存

- **定义**：a_w = 同温下产品水蒸气压 / 纯水蒸气压；与平衡相对湿度关系 $ERH(\%)=a_w\times100$。（《中国药典》微生物检查法概述 PDF）
- **《中国药典》2025 年版四部新增通则 9211**「非无菌药品微生物控制中水分活度应用指导原则」：首次把 a_w 正式纳入我国药品微生物控制体系（对非无菌制剂，含中药饮片/制剂方向）。来源：《中国药品标准》解读（MedSci 转引，2025-10-28）；国家药监局药品微生物检测重点实验室宣讲。
- **微生物生长的最低 a_w（药典/教科书级）**：
  - 细菌 0.91–0.97；酵母 0.88–0.90；霉菌 ≈0.80；多数霉菌最低 a_w 0.80，**a_w<0.65 霉菌不生长**（食品工艺学教材页；药典概述 PDF 表同量级）。
  - 黑曲霉（药材霉变常见种）**a_w ≤ 0.76 时菌落生长停滞**（《黑曲霉生长最低水分活度研究》，参考网转引，2020）。
  - 工程经验阈值：**a_w<0.70 抑制约 90% 微生物；a_w<0.60 几乎所有微生物被抑制**（大昌华嘉/梅特勒类厂商解读，标注为厂商）。
- **对中药的专门研究**：李秀珍、刘风琴、李婷婷等《水分活度用于中药饮片微生物污染控制的探讨》，《中国药事》2021, 35(5): 552–557 —— 提出**同水分含量下不同饮片 a_w 差异显著，水分合格不等于 a_w 落在安全栅栏之下**；《水分活度用于中药临方制剂微生物控制的应用现状及前景》，《上海中医药大学学报》2022（doi:10.16306/j.1008-861x.2022.01.012）。
- **结论**：13%（湿基）是**法规代理指标**；a_w 才是**生理判据**。多数药材在 10–13% 湿基时 a_w 落到 0.4–0.6 安全区，但**含糖/黏液质高的品种（枸杞、黄精、熟地）在同一水分下 a_w 更高**，需按品种定 a_w 限度。

### 3.4 (d) 干燥品质评价指标与标准测定方法

| 指标 | 定义/公式 | 测定方法（可核验） |
|---|---|---|
| 水分/干燥失重 | — | 通则 0832（含烘干法 105 ℃、甲苯法、减压干燥法、Karl-Fischer）；干基含水率 $M_t=(m_t-m_d)/m_d$，$m_d$ 用 105 ℃ 恒重法测（丹参干燥特性论文） |
| **复水率/复水比 RR** | $RR=m_2/m_1$（复水后质量/复水前质量） | 干样置于 40 ℃ 蒸馏水 30 min，沥干 20 min、拭干称重（《阶段降湿对山药热风干燥特性和品质的影响》，《中草药》2021, 52(21):2109 页）；或 25 ℃ 蒸馏水 200 mL、定时称重（怀山药微波干燥论文） |
| **色泽 ΔE / L\* a\* b\*** | $\Delta E=\sqrt{(L^*-L_0^*)^2+(a^*-a_0^*)^2+(b^*-b_0^*)^2}$ | 3NH 电脑色差仪，D65 光源，以鲜片为基准（《基于变异系数法评价不同干燥方式人参的品质差异》，《食品安全质量检测学报》2023） |
| **皱缩率/收缩率 SR** | 干燥后体积 / 原始体积 ×100% | 体积置换或卡尺+几何法；见《八角热风干燥水分变化及品质分析》，《食品工业科技》；综述《中药材干燥过程中的皱缩机制、影响因素与调控策略》，《中草药》2022, 53(9) |
| **有效成分保留率** | 干后含量/鲜样或对照含量 | HPLC：黄芪甲苷 HPLC-ELSD、毛蕊异黄酮葡萄糖苷 HPLC-UV（《基于主成分分析法研究干燥方法对黄芪药材质量的影响》，《亚太传统医药》2024, 20(1):45-50）；阿魏酸 HPLC（当归，药典） |
| 折干率 / 浸出物 / 灰分 | — | 药典通则 2201（浸出物）、2302（灰分） |
| 综合评价体系 | 水分、灰分、浸出物、折干率、色泽、有效成分 + 药典指标成分 | 综述《根茎类中药材干燥技术与装备研究进展》，《中国农业大学学报》2023 —— 明确指出"建立完整干燥品质评价体系较为困难" |

## 四、结论

1. **终点判据的现实形态是"混判"**：产线以 **SOP 定时 + 快速水分抽样（主）+ 感官手摸/色泽（辅）+ 排湿仪表平衡（过程）** 并联判定；"干燥至恒重（≤5 mg）"是实验室检验判据，不用于在线。**没有任何现行工艺是"只靠定时"或"只靠感官"的**。
2. **水分限度分三层**：① 通则 0212 兜底 **13%（湿基）**；② 《通则（试行）》**7%~13%**、WFCMS **中药材 10%~15% / 饮片 7%~13%** 的区间；③ 单品种药典限度（黄芪 10%、山药片 12%、山药 16%、当归 15%）。实际存在**20% 级别的合规宽容带**。
3. **a_w 是水分限度的物理基础，但不是现行强制项**：2025 版药典新增通则 9211 才正式引入；工程阈值 **a_w<0.6 几乎全抑制、<0.65 霉菌不生长、黑曲霉 <0.76 停滞**。含糖/黏液质品种需单独定 a_w。
4. **品质评价是"一主多辅"**：水分（通则 0832）为主，色泽 ΔE（色差仪）、复水比 RR、皱缩率 SR、有效成分 HPLC 含量、浸出物/折光为辅。**复水比与皱缩率目前无国家强制标准方法**，均为论文级自定法（见第五节证据强弱）。
5. **工艺温度区间**：热敏/含挥发油 **≤50 ℃**；淀粉/黏液质 50–60 ℃；一般根茎 55–65 ℃；上限通常 80 ℃。**总时长跨度极大：热风 4–20 h（切片/薄料）到 2–5 天（整根/薄层慢干/自然干）**。

## 六、与题面设定的对照（**明确判断，不只说"类似"**）

题面：圆柱 25 cm × r=2 cm；初温 28 ℃；初始干基 2.55 kg/kg；烘房 28→50 ℃ 后恒定；总时长 2–3 天；目标各处 <0.15 kg/kg 干基。

**符合实际的部分**

1. **初始含水率 2.55 kg/kg 干基 = 71.83% 湿基 —— 与鲜当归实测 (71.21±0.50)% 湿基（=2.47 kg/kg 干基）几乎相同**（《中草药》2022 当归论文）。鲜根类药材普遍 60–75% 湿基，**该初值完全真实，属多汁根类药材正常范围**。
2. **目标 0.15 kg/kg 干基 = 13.04% 湿基，与药典 0212 通则默认限"饮片水分不得过 13%"数值重合（13% 湿基 = 0.1494 kg/kg 干基）**。题面的 0.15 不是随手取的数，**正好是中药材行业的通用安全水分上限**。合理。
3. **50 ℃ 恒温**落在实际推荐带内：对含挥发油/热敏药材（当归、川芎）是上限、对淀粉类（山药）是低端、对一般根茎（55–65 ℃）偏低。**50 ℃ 是保守而安全的"品质优先"选择，真实存在**（黄芪最佳 60 ℃，故 50 ℃ 偏慢）。
4. **"预热平衡 + 恒温干燥"两阶段**确有生产原型：三七"预热 45 ℃ 10 h → 干燥 65 ℃ 8 h"、天麻"45 ℃ 预热 6 h → 50–55 ℃"、通用"预热 30–40 ℃ → 等速 → 减速 → 均衡"。**题面是把实际 3–4 段压成 2 段，属合理简化**；28→50 ℃ 升温对应真实"预热/升温段"。
5. **2–3 天总时长**与**晒干黄芪 60 h（2.5 天）**吻合，也落在整根厚料慢干范围。

**不寻常 / 需要说明的部分**

1. **"50 ℃ 热风 + 2–3 天"这一组合在实际中偏慢**。同样 50 ℃ 热风，鲜黄芪约 **13.5 h**、饮片带式干燥 60–80 ℃ 仅 **4–6 h**、多数药材热风 **8–20 h**。2–3 天更接近**晒干(60 h)/阴干(132 h)** 的量级。**唯一能让 2–3 天成立的条件是：料为"未切片的整根厚料 + 目标为"中心"而非平均**。题面给的正是 π r²·25 cm 的**实心大柱体（φ4 cm × 25 cm）+ 要求处处 <0.15**，与"整根"这一条件自洽 —— 但**如果实际会切片（片厚 2–4 mm，通则 0213），2–3 天就显著偏长**。建议在论文中**明确声明"整根不切片"是 2–3 天时长的前提**。
2. **题面只用温度、未给风速/装载/湿度**。真实工艺中 **风速是决定 h_m 与时长的一等参数**（黄连 3.5 m/s；产线普遍 1–3 m/s），装载量（kg/m²、铺厚 ≤5 mm 检验 / 产线 3–5 cm）同样影响时长。题面把风速折算进了给定的 $h_m=8\times10^{-7}$ m/s，这是**参数被"隐藏"而非缺失**，但正文应说明。
3. **烘房"水分浓度"（附件 1）= 湿空气含湿量 W，且 RH 从 82.0% 降到 60.4%**（见索引 B5）。即**预热段高湿、恒温段降湿**。这与真实抗结壳策略（"预热低温大排湿/避免表皮结壳"）方向一致，**是合理的**；但**真实产线的"排湿"通常伴随通风量阶跃**，而题面只有含湿量轨迹、无风量，属于简化。
4. **13% 只是"通用兜底"**。若药材是黄芪（10%）或山药片（12%），题面 13% 目标**偏松**；若是当归（15%），则**偏紧**。**题面未指明药材身份**，导致"0.15 是否达标"取决于品种 —— 这是本题的固有不定性（索引 X1/§三 已记录）。
5. **时间量级与题给 D 自洽**：附录 3 的 $D=2.4\times10^{-3}e^{-0.45/C}e^{-3850/T}$，在 T=323 K 下 C=2.55 时 $D\approx1.34\times10^{-8}$ m²/s、C=0.15 时 $D\approx7.9\times10^{-10}$ m²/s，对应 $R=0.02$ m 的扩散时间常数 $\tau=R^2/D$ 从 **≈8 h 拖长到 ≈140 h**。因此"总时长数十小时"由题给 D 直接决定，**2–3 天在模型内部是自洽的**（真实对错取决于 D 与 h_m 是否落在材料实测带内，属其他方向）。

**一句话判断**：**初值、终值、温度、两阶段框架都与真实工艺吻合；唯一"不寻常"的是"50 ℃ 热风 + 2–3 天"这一速度——它只在"整根厚料 + 中心判据"下成立，若按产线惯常切片，则 2–3 天偏长 3–10 倍。论文应显式声明"不切片整根"这一前提。**

## 七、遗留问题（≤3 条，交回主代理）

1. **GB/T 18672-2014 表 2 枸杞水分的原文数值未能直连验证**（多次转引一致为 ≤13%，与药典枸杞子 13% 同）。若论文需引用国标，建议以纸质/官方渠道复核条款号与表号。
2. **中药饮片 a_w 尚无强制限度值**：药典 9211 是"指导原则"而非限量；"a_w<0.6 安全"来自食品/微生物通识与厂商解读。若要写"13% 湿基 ⇒ a_w 落在安全区"，**需补一条具体药材（建议山药或枸杞）的吸附等温线数据**，否则只能定性表述。
3. **未找到"生产现场终点判据"的国家级操作规程原文**：现有证据为单篇论文（法半夏三法结合）+ 药品 GMP 类间接描述。"定时/恒重/含水率抽样/感官"四者**各自的现场使用比例**未找到量化调查；如需，需查中药饮片企业 SOP 模板或 GMP 验证报告原文。
